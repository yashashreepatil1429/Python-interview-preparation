# Python Interview Questions and Answers

## 1. What is Python?

Python is a high-level, general-purpose programming language. It is designed to be readable and supports several programming styles, including procedural, object-oriented, and functional programming. Python is commonly used for web development, automation, data analysis, artificial intelligence, scientific computing, and scripting.

## 2. What are Python's main features?

- **Readable syntax:** Code is designed to be clear and concise.
- **Interpreted execution:** Python implementations can run source code without a separate manual compilation step.
- **Dynamic typing:** Variable types are determined at runtime.
- **High-level data structures:** Built-in lists, dictionaries, sets, and tuples cover many common needs.
- **Multi-paradigm:** It supports procedural, object-oriented, and functional approaches.
- **Large ecosystem:** The standard library and third-party packages support a wide range of tasks.
- **Portable:** Python is available on Windows, macOS, and Linux, though operating-system-specific code may need changes.
- **Extensible:** Native extensions and interfaces allow Python to work with code written in other languages.

## 3. What are Python's advantages and disadvantages?

**Advantages**

- Its readable syntax can make programs easier to write and maintain.
- It has a large standard library and package ecosystem.
- It is useful across many fields, from scripting to data science.
- It supports rapid prototyping and has a large learning community.

**Disadvantages**

- Some CPU-bound workloads can run slower than equivalent optimized native code.
- Dynamic typing can allow certain errors to appear only at runtime; type hints and tests help reduce this risk.
- The standard CPython build has a Global Interpreter Lock (GIL) that limits parallel execution of Python bytecode across threads in many CPU-bound workloads. Other approaches, including multiprocessing and free-threaded CPython builds, are available.
- Packaging and dependency management can become complicated when projects do not isolate and document their environments.
- Python may be unsuitable for some memory-constrained or real-time systems.

## 4. What versions of Python are there?

Python 2 and Python 3 are the major language generations. Python 2 reached end of life in 2020 and should not be chosen for new projects. Python 3 is the supported generation; it has minor releases such as 3.12, 3.13, and 3.14, each with patch releases for fixes. The exact supported releases change over time, so check the official [Python downloads](https://www.python.org/downloads/) and [release status](https://devguide.python.org/versions/) pages.

## 5. What is the most stable version of Python?

There is not one version that is universally “most stable.” For a new project, choose the latest production release that your dependencies and deployment environment support, then use its latest bug-fix (patch) release. For an existing production project, use a supported release line that has been tested with that project, and pin or constrain the version in deployment. Check the official Python release-status page before selecting a version because the latest release changes over time.

## 6. What dependency-management tools are used with Python?

- **pip:** Installs packages from package indexes such as PyPI.
- **venv:** Creates isolated environments using the Python standard library.
- **pip-tools:** Helps compile and maintain pinned dependency files.
- **Poetry:** Manages project metadata, dependencies, environments, and packaging.
- **uv:** A fast tool for managing Python versions, environments, and packages.
- **Conda:** Manages environments and packages, including non-Python dependencies; it is widely used in scientific computing.

For a small project, a common starting point is `venv` plus `pip`, with dependencies recorded in a `requirements.txt` file. Use one environment per project to avoid package conflicts.

## 7. What file extension is used for Python files?

Python source files use the `.py` extension, for example `app.py`. Compiled bytecode cache files commonly use `.pyc`; these are generated files and are not normally edited directly. Python notebooks use `.ipynb`.

## 11. How does Python work internally?

In the standard CPython implementation, source code is parsed and compiled to Python bytecode. The CPython virtual machine then executes that bytecode. Python may cache bytecode in `.pyc` files to reduce work on later runs. Memory management includes reference counting and a cyclic garbage collector. Other Python implementations can work differently; for example, PyPy uses just-in-time compilation for many workloads.

## 12. Explain Python's architecture.

A simplified CPython execution path is:

1. **Source code:** The programmer writes Python code in a `.py` file.
2. **Parsing and compilation:** CPython parses the source, creates an internal representation, and compiles it to bytecode.
3. **Bytecode execution:** The Python virtual machine executes the bytecode.
4. **Runtime services:** The interpreter provides objects, memory management, exceptions, imports, and access to the standard library.
5. **Native interfaces:** C extensions and other interfaces can connect Python code to native libraries.

This describes CPython, the most widely used implementation. Jython, IronPython, and PyPy have different implementation details.

## 13. What is indentation in Python, and why is it used?

Indentation is the leading whitespace on a line. Python uses consistent indentation to mark code blocks, such as the body of a function, loop, or conditional. This replaces braces used by some languages. Colons introduce many compound statements, and indentation marks the statements inside them. Semicolons are not required to end ordinary Python statements.

Example:

```python
if score >= 60:
	print("Pass")
else:
	print("Try again")
```

Use spaces consistently; the Python style guide recommends four spaces per indentation level. Mixing tabs and spaces can cause errors.

## 15. What are variables in Python, and how do they differ from variables in other languages?

A variable name refers to an object. Assignment binds a name to an object; it does not require a separate type declaration.

```python
count = 3
name = "Mina"
count = "three"  # Valid, though changing a variable's role may reduce clarity
```

Python is dynamically typed: objects have types, and names can be rebound to objects of different types. In statically typed languages, variable types are often declared or checked during compilation. Python also supports optional type hints, which tools can use to find mistakes without changing normal runtime behavior.

## 16. What are Python's data types, and how do they compare with other backend languages?

Common built-in types include:

- **Numbers:** `int`, `float`, and `complex`
- **Boolean:** `bool`
- **Text:** `str`
- **Sequences:** `list`, `tuple`, and `range`
- **Mappings:** `dict`
- **Sets:** `set` and `frozenset`
- **Binary data:** `bytes`, `bytearray`, and `memoryview`
- **No-value marker:** `None`, whose type is `NoneType`

Python is dynamically typed, and many built-in containers can hold values of different types. Some other backend languages emphasize static typing, compile-time checks, or fixed element types for containers. Python also supports type hints, but the interpreter does not normally enforce them at runtime. As in other languages, the best choice depends on the program's needs and the tools used by the team.

## 17. What are functions in Python? Explain the syntax with an example.

A function is a reusable block of code. It can accept inputs (parameters), perform work, and return a result. Define a function with `def`; use `return` to send a result back to the caller. If no `return` statement is reached, the function returns `None`.

```python
def calculate_total(price, quantity=1):
	"""Return the total cost for the given quantity."""
	return price * quantity


total = calculate_total(12.50, quantity=3)
print(total)  # 37.5
```

Python functions are values: they can be assigned to names, passed to other functions, and returned from functions. Type hints can document expected inputs and outputs:

```python
def greet(name: str) -> str:
	return f"Hello, {name}!"
```

Unlike languages that require a method to belong to a class, Python functions can be defined at module level. Python also supports methods, closures, decorators, and anonymous functions created with `lambda`.

## 18. What types of functions, parameters, and arguments does Python support?

Common kinds of functions include:

- **Built-in functions:** Provided by Python, such as `len()` and `print()`.
- **User-defined functions:** Created with `def`.
- **Lambda functions:** Small anonymous functions written with `lambda`.
- **Methods:** Functions associated with an object or class.
- **Generator functions:** Use `yield` to produce values lazily.
- **Coroutine functions:** Use `async def` for asynchronous work.

A **parameter** is a name in a function definition; an **argument** is a value supplied when calling the function. Python supports positional-only, positional-or-keyword, keyword-only, variadic positional (`*args`), and variadic keyword (`**kwargs`) parameters.

```python
def describe(name, /, greeting="Hello", *details, punctuation="!", **extra):
	return f"{greeting}, {name}{punctuation}"


message = describe("Ari", "Hi", "student", punctuation=".", language="Python")
```

Here, `name` is positional-only, `greeting` can be positional or keyword, `details` collects extra positional arguments, `punctuation` is keyword-only, and `extra` collects extra keyword arguments. Default values let callers omit selected arguments.
